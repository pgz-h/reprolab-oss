# 第一次使用 ReproLab

打开桌面应用，选择「项目检查」并指定可信 Git 仓库。选好基线与候选版本后，发现测试、勾选需要比较的用例，再执行两版。结果页可查看新增失败、两版日志和已保存的证据。

CLI 可使用 `reprolab project review --help` 查看同一流程。已有证据 ZIP 可从桌面导入，也可以使用 `reprolab project summary` 核对摘要。安装包不附带教学项目。
