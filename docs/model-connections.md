# 模型接入与模型目录

## 添加服务

打开“选择 / 连接模型”。窗口分为“第三方模型提供商”和“自定义模型 API”。

- 第三方页选择服务商后填写 Key；需要调整地址、认证等时展开连接高级设置。
- 自定义页填写 Provider ID、显示名称、API 地址、API 协议和 Key。Provider ID 自动生成，也可修改。
- 已保存服务可从顶部切换。保存的 Key 不回显，留空继续使用；“显示”只显示本次新输入的内容。

获取目录只请求模型列表，不发送项目材料。修改地址、协议或凭据后，不会静默把旧模型或旧 Key 当成新连接已确认的配置。

## 添加与编辑模型

点击“获取可用模型”，搜索并勾选模型，再“更新列表”。初次获取默认选中返回的模型；已有目录只预选已配置项。搜索不改变隐藏项的勾选。取消不修改目录，更新保留已调好的模型内容和顺序，新模型追加在后面。未列出的原模型仍保留供核对。

也可“添加模型”手动填写。每张卡片支持：

- 模型 ID 与显示名称。
- 展开或收起详细参数。
- 上下文窗口、最大输出 token 数，支持 `1M`、`384K`、`2.3M` 等十进制写法。
- 文本、图片输入能力声明。
- 拖动排序；拖动手柄获得焦点后，也可按上、下键调整顺序。
- 删除模型；“恢复已保存目录”恢复本次打开时的目录，取消连接窗口不改写原配置。

最大输出设置会用于实际请求。Responses 使用 max_output_tokens，Anthropic 使用 max_tokens，Chat Completions 默认使用 max_completion_tokens；DeepSeek／智谱直连按其格式处理，也可在请求兼容选项中指定 max_tokens。空值沿用连接原有设置。

上下文窗口是能力声明，保存到预览绑定和请求来源，不把字符数或字节数伪装成精确 token 数。图片选项也是能力记录；ReproLab 当前检查工作流仍发送文本材料，未新增图片分析入口。未声明文本输入的模型不能用于这个文本工作流。

## 推理档位与 API 映射

展开模型卡片，启用“推理等级”。每个档位有两列：用户选择的档位与实际发送的 API 参数值。

初始提供 off、low、medium、high，可继续添加 minimal、xhigh、max；可以删除档位、修改顺序对应的值。改名时保留自定义 API 值，切换到或离开 off 时按该档位重置。不能重复档位，启用后至少保留一个非 off 档位；空参数、重复模型 ID、非法容量会明确阻止保存。

例如可以把 high 对应的 API 值写为 vendor-high。此模型保存后，日常入口仍选择“高 (high)”，实际请求使用 vendor-high。所有自定义模型和网关别名都可在卡片中声明，不需要匹配官方型号白名单。

默认按服务选择的 API 协议发送：

| 协议 | 非 off 档位 | off |
| --- | --- | --- |
| OpenAI Chat Completions | reasoning_effort=所填值 | reasoning_effort=none |
| OpenAI Responses | reasoning.effort=所填值 | reasoning.effort=none |
| Anthropic Messages | output_config.effort=所填值 | thinking.type=disabled |

网关额外需要 DeepSeek／GLM 的 thinking 开关时，在模型卡片的“请求兼容选项”中配置。用户声明决定可选项，服务是否接受仍以实际响应为准；拒绝时明确报错，不删掉参数重试。“服务默认”不发送推理参数，不等同于 off。

## 保存后使用

在目录下选择默认模型，可测试该模型或直接“保存并使用”。连接测试发送固定公开短句，可能产生 API 费用，只证明这个请求的结果。

设置页与 AI 项目验收入口按保存顺序显示模型；推理选择器直接使用该模型卡片声明的档位。每个模型记住自己的当前选择。删除当前档位会明确恢复服务默认；重命名模型不会把旧 ID 的请求选择套给新 ID。

发送前预览显示所选档位及映射值；配置改变后需重新预览。provider.json 和响应来源保存模型声明、请求参数及输出上限，记录“发送了什么”，不声称测量到服务端实际的思考量。

旧版只保存 ID／名称的配置仍可读取；0.19.0a15 的思考选择在内存中迁移为卡片声明，保存为新副本，原文件保留。关闭未保存窗口不会把未完成编辑写回旧配置。

## AI 在 ReproLab 中的用途

AI 可准备回归测试草稿、生成验收计划、解读实际结果。生成材料须审阅并实际执行。已有 pytest 测试检查、严格验收与证据校验无需模型账号。业务源码修复由开发者或外部工具完成。

本机配置使用私有文件权限，但内容是明文；不要提交或分享含 Key 的配置。接口和生成质量须用自己的账号另行验证。

设计、移植范围及许可见[模型接入实现说明](model-connection-design.md)。
