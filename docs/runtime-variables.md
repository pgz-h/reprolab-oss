# 项目运行变量

从 0.19.0a10 开始，项目的测试发现、两版比较、带 test_target 的严格项目案例及重放支持明确的运行变量。普通值随源码冻结；本机值只在执行时提供，不由 ReproLab 写入配置或运行条件记录。

## 桌面配置

1. 在项目检查中打开“检查环境 → 运行变量”。
2. 新增变量，选择“普通值 · 随快照保存”或“本机值 · 不保存值”。普通值适合测试模式、设置模块名等；令牌、口令或含凭据的连接串使用本机值。
3. 点击“预览并应用声明”。差异中包含普通值和本机变量名称，不包含本机值。确认后修改原项目，沿用现有备份、冲突检查和撤销流程。
4. 已有冻结会话需要点击“刷新工作区使用配置”，之后重新发现并核对范围。原报告和旧快照保持原样。
5. 只更新本机值时，填写后点击“使用本次值”，不必修改配置或重新冻结源码。运行时会重新核对发现范围，再用同一份解析结果启动两版。

“清除本次值”清除界面提供的值，声明仍保留；启动进程环境中的同名变量仍可提供值。桌面字段留空表示从启动进程环境读取；普通值支持空字符串。退出应用后需要重新填写本机值。

本机值按项目保存在进程内存中，不写入桌面 settings.json 或 activity.json。单个严格快照案例在执行前提供本机值确认窗口；导入的项目报告重放也会提示填写，不依赖原仓库仍在原位置。

## CLI 声明

在被测项目的 pyproject.toml 中配置，不要覆盖已有的同名表：

```toml
[tool.reprolab.pytest]
plugins = []
pass_env = ["DATABASE_URL"]

[tool.reprolab.pytest.environment]
DJANGO_SETTINGS_MODULE = "myapp.settings_test"
APP_MODE = "testing"
```

`environment` 中的字符串是可随证据分享的普通值。`pass_env` 只保存必须提供的名称；CLI 从当前启动进程的同名环境变量读取，不读取未声明变量，也不会自动加载 .env 文件。先通过自己的环境管理方式设置 DATABASE_URL，再执行原有命令：

```sh
reprolab project prepare /path/to/project --before HEAD --working-tree \
  --python /path/to/project-env/bin/python --output /path/to/sessions
reprolab project collect /path/to/session
reprolab project run /path/to/session --test 'tests/test_feature.py::test_behavior' \
  --output /path/to/reports --progress
```

准备返回的 directory 是后续会话路径。无需增加携带敏感值的 CLI 参数。缺少必要本机变量时，工具显示缺失名称并停止，不将值写入错误提示，也不会把缺值当作测试通过。

## 两版一致性与历史比较

每次正式运行在启动工作进程前解析一次变量，包括基础运行环境；该次发现以及前后两版使用同一份输入。程序中途修改父进程变量不会改变已固定的两版输入。两版均采用候选快照的声明，即使旧版还没有该配置表。

普通值和本机名称进入 report.json、工作进程记录与阶段事件，并参加证据一致性检查。本机值不保存，也不生成可公开猜测的值摘要。测试项目本身仍能修改自己进程中的变量；记录表示启动时提供的条件。

- 普通值或本机名称改变：历史比较标为条件变化。
- 存在本机值：跨轮是否相同保持未知，不计入“相同已记录条件下已解决”；本轮实际结果照常保留。
- 使用本机值的项目正式运行前会重新发现测试，避免复用无法确认值相同的旧清单；原选择缺失时停止，不静默缩小范围。
- 配置声明变化后的一键复查会停下供核对，沿用测试／插件配置变化的处理规则。

这不锁定外部服务、数据库状态、网络、系统库或随机性。相同变量输入不等于外部条件完全相同。

## 重放与隐私

导出包携带普通值、名称与执行证据。本机值需要在接收机器重新提供；预览列出 required_local_variables，实际重放前检查是否齐全。重放另存记录，原证据不变。

ReproLab 不把本机值写入配置、桌面设置或条件记录，但被测代码可以把值打印到日志、异常或测试记录中。工具不承诺自动脱敏这些输出，分享前应检查。普通值会进入源码快照、报告和可能选中的 AI 材料，不应放入敏感信息。

## 范围和限制

- 最多 64 个变量，单值最多 8 KiB，所提供值合计最多 64 KiB；名称为最多 128 字符的字母、数字或下划线，不能以数字开头。
- 同名变量不能同时是普通值和本机值。PATH、PYTHON*、PYTEST*、LD_*、DYLD_*、REPROLAB_* 保留给解释器、插件加载和执行控制，不能覆盖。
- 项目模式和带 test_target 的严格项目案例读取这份配置；独立 regression.py 案例保持原来的隔离方式。
- 桌面本机值输入覆盖项目检查、项目报告重放和单个严格快照项目案例。批量、AI 计划及旧 Git 案例入口中，属于项目模式的检查目前从启动进程环境读取本机值；不会隐式借用另一个项目或案例的界面值。
- 变量只用于测试执行，不自动传入模型服务请求或依赖安装，也不负责启动数据库等服务。
- 没有声明变量时保留原有行为。旧报告可继续检查；带新变量声明的材料需要 0.19.0a10 或后续兼容版本读取。
