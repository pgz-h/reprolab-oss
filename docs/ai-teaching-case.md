# 真实模型起草并验收：零值应该参与平均数计算

## 问题与检查

函数 mean 接收一组数字并计算平均值。旧版用 `[value for value in values if value]` 过滤数据，把有效的 0 也丢掉。修复版使用 `list(values)`，保留 0。

问题描述明确给出输入 `[0, 2, 4]` 和应得到的结果 `2.0`。提供给模型的上下文只有 measurements.py 的两个版本，总计 464 字节；没有提供现成测试。

模型生成的测试直接调用 `mean(inputs)`，以 `pytest.approx(2.0)` 断言真实返回值，并记录输入、实际和预期。旧版预期故障由模型在运行前声明为 AssertionError，消息包含“应把 0 计入样本总数”。

## 过程记录与实际限制

第一次请求在 120 秒后超时。第二次调低输出上限后收到响应，但旧版错误信息没有记录具体停止原因，不能确定是截断还是其他不完整状态。第三次恢复 8192 上限、允许等待 300 秒，收到完整的模型文本。

真实响应外有 JSON 代码围栏，测试导入语句位于模块顶层 try/except 中，触发当时解析器的两处限制。我们用失败测试复现并修复这些兼容问题，然后复用第三次调用的原始响应完成保存，没有再调用模型，也没有手工改写生成的测试去追求通过。

模型假设中的 src 布局回退在这个最小样例中并非必需；测试只证明给定输入对应的行为，不覆盖空输入、异常数值或整个软件。原始响应、说明、假设和测试指纹均已保留。
