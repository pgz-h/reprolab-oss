## 实际桌面工作流

通过真实 Qt 窗口与按钮，在新建的非私有教学 Git 项目上验证：

1. 创建案例并固定修复前后提交；保存阶段没有自动执行代码。
2. 在打包应用内用实际工作进程运行刚创建的案例，结果 verified。
3. 在草稿向导手工选择代码上下文并准备 prompt；没有模型响应文件、没有模型调用。
4. 搜索、勾选两个案例，批次实际完成且全部 verified，生成总览和两份报告。
5. 第二项运行中取消，批次为 cancelled，第一项 verified 保留。
6. 最终 DMG 只读挂载后通过 macOS Launch Services 启动，重复上述新流程；重启读取案例、草稿及报告。

自动化方式是 Qt Test 操作实际窗口，不等同于人工 Finder 拖拽记录。新建向导的原生文件选择由具体文件路径注入替代，但元数据读取、表单设置、保存、测试执行、生成文件和批次取消均为真实操作。CLI 与现有历史数据保持兼容。

所有截图/JSON 记录在本机 outputs/reprolab/previews/v0.11.0-*；没有读取用户 Key 或向远程模型发送任何源码。测试中的教学项目不能当作外部采用证明。
