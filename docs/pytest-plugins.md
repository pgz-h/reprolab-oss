# 项目测试插件与导入方式

适用于 0.19.0a2 及后续版本。ReproLab 默认不自动加载所选环境中的所有 pytest 插件，也不执行项目 `addopts` 中可能改变选择范围、提前退出或并行运行的参数。

需要插件的项目，可在**被测项目**的 `pyproject.toml` 添加明确配置。例如已经在项目环境安装 pytest-asyncio 的异步项目：

```toml
[tool.reprolab.pytest]
plugins = ["pytest_asyncio.plugin"]
import_mode = "importlib"
```

`plugins` 支持 pytest 插件模块名或入口名，最多 32 项。可指定已经随项目保存的本地插件模块。插件需要在所选 Python 或相应源码快照中可用，不会自动安装。`import_mode` 可省略，或选择 `prepend`、`append`、`importlib`；应沿用项目需要的方式，不保证一种模式适合所有项目。原生 pytest 配置和每版 conftest 继续生效，`addopts` 仍被清空。

在 0.19.0a6 的“检查环境 → pytest 插件”页可以查看安装入口、手动添加插件，并预览后应用到原项目；也可继续复制配置。提供原项目配置撤销及刷新工作区入口，冻结源码保持原样。在“检查环境”可以查看声明，在发现日志和离线报告可以查看本次配置。修改声明后须刷新当前工作区，旧会话仍使用旧快照。

两版均使用**变更后快照**声明的同一插件及导入配置，包括旧版本尚无该配置表时。单项项目案例也使用候选快照的配置；独立 regression.py 案例保持原来的隔离运行方式。

该配置随源码证据保存，导出、导入和明确重放后继续适用。配置格式错误会停止操作；插件缺失、加载失败或修改明确选择的插件钩子不会变成通过。记录缺失的旧报告会显示配置未知。

只声明确实需要的插件。测试配置、conftest 和插件都可能执行可信项目代码；这个功能不提供安全隔离。

从 0.19.0a10 开始，同一表还支持 environment 和 pass_env，详见[运行变量](runtime-variables.md)。编辑插件时会保留已有变量声明；变量修改同样需要预览、应用及刷新。
